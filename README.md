# Authentication

### Учебный проект в TomorrowSchool

# Аудитору

Проект построен на базе нашего проекта real-time-forum. Функционал проверялся в рамках других аудитов.

В этом проекте реализована только регистрация и вход через Google и GitHub.

Так как ранее был ряд требований с предудущих работ функционал может не соответсововать лучшим практикам на текущий день, но полностью соответствует требованиям заданиям TomorrowSchool. Для удобства тестирования рекомендуется использовать docker compose. 

После аудита приложения из Google и GitHub будут удалены. Ключи не копируйте и неиспользуйте.

## Структура проекта (наследовано от нашего предыдущего проекта)

```
main.go                     — точка входа
internal/
  handlers/                 — HTTP-обработчики
  chat/                     — хаб WebSocket-соединений (real-time события)
  models/                   — структуры данных
  repository/               — слой работы с SQLite
  server/                   — сборка mux и маршрутов
  templating/               — кэш шаблонов
ui/
  templates/                — HTML-шаблоны (layout + страницы)
  static/css/               — стили
  static/js/realtime.js     — real-time клиент (WebSocket: сообщения, тосты, пагинация, счётчики реакций)
```

## Валидация на сервере

- Email проверяется по RFC-адресу и OATH
- Username непустой (до 40 символов) и не занят
- Пароль — минимум 6 символов
- Длины заголовка/текста поста и комментария ограничены


### Запуск через Docker compose

```bash
docker compose build # можно пропустить, если собираете впервые
docker compose up    # запуск
```

*Если на Mac в alem.ai не работает docker compose — найдите и запустите Docker Desktop.
При первом запуске выберите настройки, не требующие пароля администратора; вход в учётную запись можно пропустить.*
